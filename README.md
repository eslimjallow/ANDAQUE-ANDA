# ANDA QUE ANDA - Sitio Web

Sitio web oficial del grupo de teatro **ANDA QUE ANDA** de Las Palmas de Gran Canaria.

## 📋 Descripción

Sitio web responsive desarrollado para mostrar las producciones, agenda, galería, miembros y contacto del grupo de teatro ANDA QUE ANDA. El sitio está optimizado para funcionar perfectamente en todos los dispositivos: iPhone, Android, tablets, laptops y desktop.

## 🚀 Características

- ✅ **Diseño Responsive**: Optimizado para móviles, tablets y desktop
- ✅ **Navegación Intuitiva**: Menú adaptativo con scroll horizontal en móvil
- ✅ **Páginas Incluidas**:
  - Inicio (Homepage con hero section y countdown)
  - Producciones (Detalles de todas las obras)
  - Agenda (Próximos eventos)
  - Galería (Fotos y videos de eventos pasados)
  - Miembros (Perfiles del equipo)
  - Asociación (Historia y valores)
  - Contacto (Formulario y reservas)

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica
- **Tailwind CSS**: Framework CSS utility-first (via CDN)
- **JavaScript**: Funcionalidad interactiva
- **Responsive Design**: Mobile-first approach

## 📱 Optimizaciones Móviles

- Viewport configurado para permitir zoom y mejorar accesibilidad
- Navegación móvil con scroll horizontal sin scrollbar visible
- Tamaños de texto adaptativos (xs → sm → md → lg)
- Botones táctiles con feedback visual
- Espaciado optimizado para pantallas pequeñas
- Imágenes responsivas con lazy loading

## 🌐 Uso

### Versión Estática
Simplemente abre `anda-que-anda-static/index.html` en tu navegador.

### Versión con Vite
```bash
cd anda-que-anda-site
npm install
npm run dev
```
